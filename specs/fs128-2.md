# FS/128-2

FS/128-2 is a small modification of the [original FS/128 spec](https://github.com/BeauConstrictor/OS-128/blob/main/filesystem.md) that is backward-compatible (as long as an original FS/128 filesystem has no more than 16 files on disk).

## The Change

There is only really one change from the original spec: the root directory contains 16 entries, and takes up just a single sector (the original root directory allowed 64 entries and took up 4 sectors). This change makes the filesystem much easier to implement, and leaving the other 3 sectors reserved for future use.

## A Small Note on Hardlinks

The concept of hardlinks (where multiple directory entries point to the same file on disk) that is present in other filesystems is not be allowed in FS/128-2. There should only be a single directory entry that points to any file on disk (not just the same initial sector, but any sector in the same file).
