These commands are defined internally. To run an external program,
type it's name.

Commands:

[32mhlp       [90m        - [0mShow this help
[32mdsk [33m[disk]        [90m- [0mChange disk
[32mdir       [90m        - [0mList files in the directory
[32mbye       [90m        - [0mShutdown the machine
[32msys       [90m        - [0mEnter the system firmware
[32mcls       [90m        - [0mClear the screen
[32mfmt [33m[disk]        [90m- [0mFormat a device with FS/128
[32mnew [33m"name"        [90m- [0mCreate a new file with a specified name
[32mren [33m[file] [33m"name" [90m- [0mChange the name of a file
[32mprn [33m[port] [33m[file] [90m- [0mPrint a file to a port
[32mdev       [90m        - [0mList installed devices
[32musg       [90m        - [0mCheck how much of the disk is in use
[32msiz [33m[file]        [90m- [0mCheck the size of a file
